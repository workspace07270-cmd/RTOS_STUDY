# React–Spring Boot–RTOS 연동 로또번호 발급 과제

## 1. 과제 개요

4일차 예제를 참고하여 React, Spring Boot, RTOS를 연동한 **로또번호 5세트 발급 시스템**을 구현한다.

React에서 **로또번호 5세트 발급하기** 버튼을 누르면 Spring Boot가 로또번호 5세트를 생성하여 RTOS로 전달한다. RTOS는 전달받은 로또번호를 출력한 뒤 Spring Boot에 완료 신호를 보내고, React는 Spring Boot로부터 완료 상태를 확인한 후 다음 발급 요청을 할 수 있어야 한다.

> 로또번호 1세트는 1부터 45까지의 서로 다른 숫자 6개로 구성하며, 오름차순으로 정렬한다. 한 번의 요청으로 총 5세트를 생성한다.

## 2. 시스템 동작 순서

1. 사용자가 React 화면에서 **로또번호 5세트 발급하기** 버튼을 누른다.
2. React가 Spring Boot에 로또번호 발급을 요청한다.
3. Spring Boot가 로또번호 5세트를 생성하고 요청 상태를 `PENDING`으로 저장한다.
4. 중복 요청을 방지하기 위해 React의 발급 버튼을 비활성화한다.
5. RTOS가 Spring Boot의 대기 명령을 조회하여 로또번호를 전달받는다.
6. RTOS가 전달받은 로또번호 5세트를 콘솔에 출력한다.
7. 출력이 끝나면 RTOS가 Spring Boot에 완료 신호를 전송한다.
8. Spring Boot가 요청 상태를 `COMPLETED`로 변경한다.
9. React가 완료 상태를 확인하여 화면에 완료 결과를 표시한다.
10. React가 발급 버튼을 다시 활성화하여 다음 요청을 받을 수 있게 한다.

## 3. 영역별 구현 요구사항

### 3.1 React

- **로또번호 5세트 발급하기** 버튼을 제공한다.
- 버튼 클릭 시 Spring Boot의 발급 API를 호출한다.
- 처리 중에는 버튼을 비활성화하여 중복 요청을 막는다.
- 요청 상태가 `COMPLETED`가 될 때까지 Spring Boot에 상태를 주기적으로 조회한다.
- 완료 신호를 받으면 완료 메시지 또는 발급 결과를 화면에 표시한다.
- 완료 후 버튼을 다시 활성화한다.

### 3.2 Spring Boot

- React의 로또번호 발급 요청을 받는다.
- 한 요청마다 로또번호 5세트를 생성한다.
- 각 세트는 다음 조건을 만족해야 한다.
  - 번호 범위: 1~45
  - 세트당 번호 수: 6개
  - 세트 내부 중복 없음
  - 오름차순 정렬
- 생성한 로또번호와 요청 상태를 관리한다.
- RTOS가 대기 중인 명령을 조회할 수 있는 API를 제공한다.
- RTOS에 로또번호 5세트를 전달한다.
- RTOS의 완료 신호를 받아 요청 상태를 `COMPLETED`로 변경한다.
- React가 요청 상태와 결과를 조회할 수 있는 API를 제공한다.

### 3.3 RTOS

- Spring Boot에 주기적으로 접속하여 대기 중인 명령을 조회한다.
- Spring Boot에서 로또번호 5세트를 전달받는다.
- 전달받은 로또번호를 세트별로 콘솔에 출력한다.
- 모든 출력이 끝나면 Spring Boot에 완료 신호를 전송한다.
- 같은 요청을 중복 실행하지 않도록 처리한다.

## 4. API 구성 예시

4일차 예제의 API 구조를 활용하며, 다음 경로는 구현에 맞게 변경할 수 있다.

| Method  | API 경로                            | 호출 주체 | 기능                           |
| ------- | ----------------------------------- | --------- | ------------------------------ |
| `POST`  | `/api/lotto-requests`               | React     | 로또번호 5세트 발급 요청       |
| `GET`   | `/api/lotto-requests/{id}`          | React     | 요청 상태 및 결과 조회         |
| `GET`   | `/api/lotto-requests/pending`       | RTOS      | 대기 중인 명령과 로또번호 조회 |
| `PATCH` | `/api/lotto-requests/{id}/complete` | RTOS      | 출력 완료 신호 전송            |

## 5. 완료 조건

- [ ] React에서 발급 버튼을 누르면 Spring Boot에 요청이 전달된다.
- [ ] Spring Boot가 조건에 맞는 로또번호 5세트를 생성한다.
- [ ] RTOS가 Spring Boot에서 로또번호를 전달받는다.
- [ ] RTOS 콘솔에 로또번호 5세트가 정상적으로 출력된다.
- [ ] RTOS가 출력 완료 신호를 Spring Boot에 전송한다.
- [ ] Spring Boot에서 명령 수신 및 상태 변경 내역을 확인할 수 있다.
- [ ] React가 완료 상태를 확인한 뒤 발급 버튼을 다시 활성화한다.
- [ ] 처리 중에는 React의 발급 버튼이 중복 동작하지 않는다.
- [ ] 연속으로 두 번 이상 발급하여 전체 흐름이 반복 동작하는지 확인한다.

### 6.2 실행 증빙 이미지

총 **3장**의 이미지를 제출한다.

1. **RTOS 로또번호 출력 결과**
   - 로또번호 5세트가 모두 출력된 콘솔 화면

2. **Spring Boot 명령 처리 내역**
   - React의 요청 수신 내역
   - RTOS의 명령 조회 내역
   - RTOS 완료 신호 수신 및 `COMPLETED` 변경 내역
3. **React 실행 화면**
   - 로또번호 발급 완료 상태가 표시된 화면
   - 다음 발급을 위해 버튼이 다시 활성화된 상태

## 7. 실행 확인 시 주의사항

- Spring Boot 서버를 먼저 실행한 후 RTOS와 React를 실행한다.
- RTOS와 Spring Boot가 서로 접근할 수 있도록 서버 주소와 포트를 확인한다.
- React의 API 주소와 CORS 설정을 확인한다.
- 네트워크 오류나 처리 실패가 발생한 경우 버튼이 영구적으로 비활성화되지 않도록 예외 처리를 권장한다.
- 요청 ID를 기준으로 각 명령의 생성, 전달, 완료 상태를 추적할 수 있도록 로그를 남긴다.
